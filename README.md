## Hi there 👋

I'm Beanut. I do retro game translations utilizing AI with all my heart and soul.

Visit the [Project Site](https://beanutrom.github.io/) to see everything in a nice easy to navigate webpage showing detailed releases and project status' including various media!

All of these projects have had substantial work done on them, and are near complete or are complete translations in their current state, they mostly just need playtesting.
